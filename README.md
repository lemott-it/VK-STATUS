# VK-STATUS
Проект для отслеживания  online/offline, лайков, комментариев пользователей VK, Создан на основе Api VK вся  полученная информация является общедоступной.
Для получения ключа api Зайдите по ссылки https://dev.vk.com/ru , создайте мини приложение, затем перейдите в раздел разработка затем в раздел ключи доступа вам понадобится сервисный ключ. После получения ключа заносим его в ког в раздел 'ACCESS_TOKEN'
